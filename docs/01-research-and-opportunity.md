# 01｜研究依据与产品机会

## 1. 原始研究

**论文：**《用户能动性对算法“破茧”的影响研究——以“抖音”平台为例》

研究以技术接受模型为主要理论框架，通过问卷调查和深度访谈，分析抖音用户对“破茧”相关功能的认知、使用、感知有用性和信息多元化获得感。

### 已有研究事实

- 有效问卷：385 份；研究对象以大学生用户为主。
- 深度访谈：12 位不同背景用户。
- 问卷使用李克特五点量表，测量信息茧房感知、功能使用频率、感知有用性、感知易用性和信息多元化获得感。
- 论文纳入分析的功能包括搜索、频道分类、热搜榜、“不感兴趣”、内容偏好设置、精品内容推荐和同城附近页。
- 信息茧房感知均值为 3.3654/5；“内容越来越相似”题项均值为 3.58/5。
- 搜索功能的知道比例为 97.9%，经常使用比例为 88.1%；感知有用性均值为 3.88/5。
- 内容偏好设置的感知有用性均值为 3.48/5；访谈反馈中出现操作麻烦、效果不确定等感受。
- 多元线性回归中，主动寻求信息与信息多元化感知呈正向关联（标准化 β=0.247，p<.001）；搜索功能感知有用性也呈正向关联（β=0.280，p<.001）；“不感兴趣”按钮感知有用性呈正向关联（β=0.123，p=.046）。
- 频道分类（p=.086）、热搜榜（p=.370）、内容偏好设置（p=.774）和同城附近页（p=.984）的感知有用性，在该模型中未达到统计显著。

## 2. 研究如何转成产品机会

**观察：** 用户较常使用可以主动发起、即时操作的搜索；对需要进入设置、修改长期偏好的方式，用户报告的感知有用性较低，并提到不确定调整是否有效。

**机会假设：** 把“主动探索”入口放在用户正在观看的内容语境里，减少用户从推荐流切换到设置页面或重新组织搜索词的成本；让探索范围可选、影响范围可见、退出路径明确。

**方案方向：** 从视频操作菜单进入“拓展这个兴趣”，选择一个探索方向，进入一次性探索内容流，并通过“喜欢这类 / 减少这类”反馈微调本次体验。

## 3. 必须保留的研究边界

- 回归结果是统计关联和预测关系，不代表因果关系。
- 研究样本以大学生为主，不能直接代表所有短视频用户。
- 核心量表主要来自自我报告；用户对信息多元化的感知不等于内容实际多样性。
- 论文的回归表中多个功能感知有用性变量 VIF 较高（部分超过 10），解释单个回归系数和变量排名时应谨慎。
- 论文未进行线上产品实验，也没有该产品功能的行为埋点数据。
- 下文原型、功能与指标均是产品方案，不是论文的实验结论。

## 4. 待验证的问题

1. 用户是否能理解“拓展这个兴趣”与普通搜索的区别？
2. 从当前视频进入探索，是否比离开推荐流再搜索更省力？
3. 用户希望探索的是相邻主题、完全新主题，还是由系统提供方向？
4. “本次探索，不更改长期偏好”的说明是否足以建立控制感？
5. 用户会不会把探索内容误解为平台对其长期兴趣的判断？
6. 怎样定义有价值的探索：多看一条不同主题内容，还是持续探索并感到相关？

## 5. 设计原则

- **用户发起：** 探索由用户主动选择，不自动切换推荐策略。
- **范围可见：** 开始前明确主题和本次探索的影响范围。
- **随时可退：** 保留明显的退出入口，返回进入前的浏览位置。
- **相关但有新意：** 先从相邻主题探索，避免无关内容造成挫败。
- **反馈可理解：** 反馈后解释它影响本次探索还是长期偏好；MVP 默认只影响本次探索。
