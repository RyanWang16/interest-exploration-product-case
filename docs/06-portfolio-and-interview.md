# 06｜作品集与面试讲述

## 1. 项目介绍（约 60–90 秒）

“我的毕业论文关注短视频用户能动性与信息多样性体验的关系，研究包括385份有效问卷和12次深度访谈。分析发现，主动寻求信息、以及用户对搜索功能有用性的评价，与信息多元化获得感呈正向关联。基于这一发现，我设计了一个推荐流兴趣探索方案：用户可以从当前视频选择相关或相邻主题，进入一次性探索流，并随时反馈或退出。项目产出包括需求文档、用户流程、低保真原型和测试计划。目前方案还没有上线或完成用户测试，后续需要通过可用性测试和线上实验验证。”

## 2. 简历项目表述参考

**推荐流「兴趣探索」产品方案｜个人项目**

- 基于毕业论文的385份有效问卷、12次深度访谈及回归分析，梳理用户主动探索、搜索工具感知有用性与信息多元化获得感之间的关系。
- 据此提出用户主动发起的兴趣探索方案，设计方向选择、一次性探索流、内容反馈与退出流程，整理需求说明和低保真交互原型。
- 制定探索性可用性测试任务与线上 A/B 实验框架，定义主要指标、体验护栏及结果解释边界；方案尚未上线，未产生实验结果。


## 3. 可准备的面试追问

### 为什么要做这个功能？

回到论文中已观察到的用户主动搜索和感知有用性结果，说明它提供的是设计启发，不是功能效果的因果证明。解释“降低主动探索成本”是产品假设，需要测试。

### 为什么不直接改推荐算法？

MVP 选择用户主动调用、范围清晰、可退出的探索入口，便于先验证需求和交互；是否需要算法策略调整，要等内容供给、用户反馈和实验结果支持后再讨论。

### 怎么判断功能有效？

不只看入口点击。先看入口曝光后是否完成有效探索播放，再检查内容相关性、负反馈和常规推荐护栏。最终指标定义和样本量需要与数据团队基于基线共同确定。

### 研究有哪些局限？

样本以大学生为主，数据主要来自问卷自报告和访谈，不能直接推断所有用户行为；回归模型中部分预测变量 VIF 较高，系数解释需谨慎；没有产品埋点或真实因果实验。

### 现在的结果是什么？

研究阶段的结果是问卷和访谈发现；产品阶段的产出是需求方案、流程、原型和验证计划。没有真实用户测试、上线或 A/B 结果。

## 4. 项目展示顺序

1. 研究问题与用户场景。
2. 研究设计和关键发现。
3. 从研究发现到产品假设的推理链。
4. 核心流程和原型。
5. 可用性测试如何验证理解和操作。
6. A/B 测试如何评估使用价值与体验风险。
7. 局限、待验证事项和下一步计划。
