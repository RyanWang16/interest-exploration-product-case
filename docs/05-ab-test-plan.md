# 05｜A/B 测试计划

## 1. 实验问题与假设

**问题：**在推荐流中提供用户主动发起、可选择并可退出的兴趣探索入口，能否让更多用户完成一次有效的跨主题探索，同时维持常规内容体验？

**假设：**相较现有推荐流，展示「拓展这个兴趣」入口会提升有效探索转化率；如果方向选择清楚且影响范围可见，负反馈和常规推荐体验不会出现不可接受的恶化。

该假设尚未验证。

## 2. 实验设计

- **实验单位：** 用户 ID；同一用户在实验期间固定分组，避免跨组污染。
- **对照组：** 现有推荐流，不展示探索入口。
- **实验组：** 在适用视频的操作菜单中展示探索入口，并提供方向选择与一次性探索流。
- **适用用户：** 符合产品安全、内容质量和技术条件的活跃用户；具体纳入条件由产品、数据和安全团队确定。
- **分流：** 用户级随机分配；实验开始前确认曝光埋点、事件去重和跨设备身份规则。
- **周期：** 至少覆盖完整周内使用周期，并达到预先计算的样本量；不按固定天数提前宣称结论。

## 3. 指标定义

### 主要指标：有效探索转化率

**公式：** 实验组中，看到入口后点击入口且至少完成一次有效探索播放的去重用户数 ÷ 看到入口的去重用户数。

**有效探索播放口径：** 优先沿用平台现有有效播放定义；若本方案必须单独定义，需由产品和数据团队在实验前确定阈值，并记录到实验配置中，不在看到结果后调整口径。

### 次要指标

- 探索方向选择率。
- 探索流有效播放数/用户。
- 探索中的主题类别数或主题多样性指标（需内容分类准确性评估）。
- 用户主动退出率、方向更换率。
- 探索完成后的主观相关性和控制感短问卷（抽样）。

### 护栏指标

- 探索内容快速划走率和“不感兴趣”率。
- 常规推荐流有效播放、会话体验和短期回访变化。
- 投诉、隐藏内容、误解长期偏好的反馈。
- 内容安全、低质内容和分类错误率。

## 4. 样本量与统计方案

- 用实验前的基线转化率、最小可检测变化（MDE）、显著性水平和统计功效计算样本量。
- MDE 应根据产品价值和用户体验风险共同设定，不从实验后数据反推。
- 预先登记主要指标、护栏指标、观察周期、剔除规则和多重比较处理方式。
- 实验期间监控数据质量和安全护栏；除预先定义的安全停止条件外，避免反复窥看显著性并提前结束。
- 实验结束报告绝对差异、相对差异、置信区间及分群结果；避免只报告显著性或单一均值。

## 5. 决策规则

- **扩大实验：** 主要指标达到预设效果标准，且护栏没有达到预设恶化边界；结论在关键用户分群中没有明显风险。
- **迭代后复测：** 入口点击增加但有效探索播放不变，或用户常因方向不清、内容不相关而退出。
- **停止或回滚：** 常规体验、负反馈、误解或安全指标触发预设停止条件。
- **结果不确定：** 样本量不足、置信区间过宽、埋点异常或分群结果方向不稳定时，不下“有效/无效”结论，先补数据或调整实验设计。

## 6. 风险和解释边界

- 点击率提升不等于用户真正获得更多信息多样性。
- 内容类别数提升不等于内容有价值或相关。
- 线上实验结果只适用于实验对象、时间段、推荐策略和内容分类口径。
- 需与算法、内容安全、隐私和数据团队确认实现方式及合规要求。
- 目前没有真实 A/B 测试数据，本文件只描述验证方案。
