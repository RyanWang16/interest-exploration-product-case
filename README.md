# 推荐流「兴趣探索」产品方案

> 个人产品策划案例草案。它从毕业论文的用户研究发现延展而来，研究结果与产品假设、设计方案、测试计划分开记录。

## 项目概览

- **项目类型：** 基于学术研究的个人产品方案延展
- **产品场景：** 短视频推荐流中的主动内容探索
- **核心问题：** 用户想接触兴趣范围之外的内容时，如何更容易主动发起探索，同时保留控制感并及时退出？
- **当前状态：** 研究依据已存在；需求方案、流程、交互原型及验证计划为方案设计，尚未进入真实用户测试或线上实验。
- **重要边界：** 本方案不是抖音官方产品设计，也没有真实上线、业务数据或实验结果。原论文基于自报告数据，回归结果说明变量之间的统计关联，不证明因果。

## 如何查看原型

直接用浏览器打开 `prototype/index.html`。原型为静态演示，使用模拟文案和按钮，不连接真实推荐系统，也不会保存个人数据。

## 建议的作品集补全步骤

1. 先阅读研究依据，确认你能解释问卷、访谈、回归结论和研究局限。
2. 亲自走一遍原型，修改你认为不合理的入口、文案和流程。
3. 找 5–8 位目标用户完成探索性可用性测试，记录真实观察，不预设结果。
4. 根据观察迭代原型，留下版本差异和设计决策。
5. A/B 测试当前只有方案设计；除非获得平台数据并实际执行，不要声称实验有效或指标提升。
