# 推荐流「兴趣探索」产品方案

基于毕业论文的用户研究，探索如何让用户从短视频推荐流主动发起内容探索，并能自主选择范围、随时退出。

## 项目概览

- **项目类型：** 毕业论文研究延展的个人产品方案
- **产品场景：** 短视频推荐流中的主动内容探索
- **核心问题：** 用户想接触兴趣范围之外的内容时，如何更容易主动发起探索，同时保留控制感并及时退出？
- **当前进度：** 已完成需求方案、核心流程、交互原型和验证计划，尚未开展真实用户测试或线上实验。
- **项目边界：** 本方案为个人研究延展，并非抖音官方设计，目前没有上线或实验数据。论文回归结果反映变量间的统计关联，不能据此推断因果。

## 如何查看原型

直接用浏览器打开 `prototype/index.html`。原型为静态演示，使用模拟文案和按钮，不连接真实推荐系统，也不会保存个人数据。

## 建议的作品集补全步骤

1. 先阅读研究依据，确认你能解释问卷、访谈、回归结论和研究局限。
2. 亲自走一遍原型，修改你认为不合理的入口、文案和流程。
3. 找 5–8 位目标用户完成探索性可用性测试，记录真实观察，不预设结果。
4. 根据观察迭代原型，留下版本差异和设计决策。
5. 线上 A/B 测试仍处于方案阶段；功能效果需要在取得平台数据并完成实验后评估。
